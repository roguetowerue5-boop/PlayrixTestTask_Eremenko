# Playrix — тестовое (AI-pilled producer)

Инструмент для автоматического наполнения коллекционных карточек и сборки страницы набора.

## Что внутри

| Папка | Назначение |
|--------|------------|
| `OfferForge/` | Веб-приложение: бриф → 3–5 вариантов набора → арт (OpenRouter / fal LoRA) |
| `OfferBuilder/` | Сборка UI-страницы коллекции из `Cutted` + иконок |
| `Cutted/` | UI-элементы для сборки |
| `Framing/` | Референсные целые экраны |
| `Icons/` | Эталонные арты карточек (стиль / датасет LoRA) |
| `Packs/` | Примеры финальных паков |
| `RuleForBuilding/` | Правила сборки |
| `OfferForge/briefs/` | Готовые тексты для 3 кино-наборов |

## Быстрый старт

```bat
cd OfferForge
run.bat
```

Откроется `http://127.0.0.1:8848`. Ключи API вводятся в UI (**Провайдеры** / **LoRA Trainer**) и хранятся только локально в `OfferForge/config/secrets.json` (в git не попадает).

Сборка страницы коллекции:

```bat
cd OfferBuilder
run_and_check.bat
```

## Стек

- FastAPI + статичный UI
- OpenRouter (текст, vision, картинки)
- fal.ai (обучение / инференс Flux LoRA на стиле Icons)

## Важно

Не коммитьте API-ключи. После клона вставьте свои ключи в интерфейсе.

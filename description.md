В этой папке находятся файлы для создания офферов с помощью AI инструментов.

Cutted - содержит составные части UI интерфейса из которых состоит оффер.

Framing - содержит уже собранный UI интерфейс со всеми UI элементами в себе.

Icons - содержит иконки, которые используются для вставки внутри framing (внутри карточек товаров для офферов)

Packs - финальные изображения, которые требуются от программы для создания офферов.



Описание работы:

Программа состоит из 3 основных элементов:
1. Сборка интерфейса

2\. Генерация изображения офферов

3\. Сборка паков



Сборка интерфейса соуществляется через OfferBuilder

Генерация изображений происходит через OfferForge

Сборка паков также должна будет происходит либо через расширение системы OfferForge либо через отдельную тулзу.

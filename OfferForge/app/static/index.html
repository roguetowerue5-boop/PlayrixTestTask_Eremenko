1. Ключ fal.ai

Из кабинета fal → API Keys. Хранится в config/secrets.json как провайдер fal_lora.

Модель fal-ai/flux-lora-fast-training, режим стиля. Zip ~127 МБ грузится multipart через fal-client. После 500 steps стиль часто слабый — лучше 1000–1200 (~$10–12).

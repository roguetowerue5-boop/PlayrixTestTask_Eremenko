LoRA Trainer

Обучение Flux LoRA на Icons через fal.ai. OpenRouter ключ остаётся для текста и отката картинок — оба ключа работают вместе.

1. Ключ fal.ai

Из кабинета fal → API Keys. Генерация — обычный API key (fal_lora). Баланс в сайдбаре — Admin key (fal_admin / FAL_ADMIN_KEY), endpoint /v1/account/billing требует scope ADMIN.

2. Датасет

3. Обучение

Модель fal-ai/flux-lora-fast-training, режим стиля. Zip ~127 МБ грузится multipart через fal-client. После 500 steps стиль часто слабый — лучше 1000–1200 (~$10–12).

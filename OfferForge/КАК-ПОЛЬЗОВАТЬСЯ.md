# Как получить рабочий результат

Сейчас в интерфейсе: **Создание наполнения**, **Собрать коллекцию**,
плюс AI (провайдеры / модели) и промпты.

## Запуск

```bat
run.bat
```

Откроется `http://localhost:8848`.

## Создание наполнения

1. Название + описание коллекции.
2. Пресет моделей (роли `concept` и `render`).
3. **Создать 10 карточек** — через OpenRouter: сначала список предметов
   (промпт `collection_fill`), затем арт каждой (промпт `art`).
4. У каждой карточки — **Перегенерировать**.
5. **Перенести в сборку** — имена, звёзды и картинки уходят в «Собрать коллекцию».

Поведения правятся во вкладке **Промпты**.

## Собрать коллекцию

Сборка страницы на материалах `Cutted` без моделей. Можно подставить арт
из наполнения или свои файлы. Номер страницы временно отключён.

## Ключ

**AI → Провайдеры** — ключ OpenRouter (нужен и для text, и для images).
**AI → Модели** — роли `concept` / `render`.
